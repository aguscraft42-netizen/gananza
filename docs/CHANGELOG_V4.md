# Gananza V5 — Cambios de Fase 1

## Producto

- Se agregó landing definitiva de demostración.
- Se creó acceso con registro e inicio de sesión simulados.
- Se agregó onboarding de tres pasos.
- Se definieron seis estados de tareas.
- Se completó el flujo iniciar → completar → pendiente → confirmada.
- Se agregó información de proveedor, vigencia y condiciones.
- Se desarrolló un retiro completo en tres pasos.
- Se agregó comprobante de retiro.
- Se creó sección de soporte y preguntas frecuentes.
- Se mejoró perfil y configuración.
- Se amplió el panel administrativo.

## UX

- Estados vacíos y de carga.
- Mensajes de validación.
- Notificaciones flotantes.
- Confeti solo en confirmaciones relevantes.
- Modo sin conexión simulado.
- Opción de ocultar saldo.
- Navegación móvil inferior.
- Adaptación a escritorio y celular.

## Marca y estética

- Dirección fintech oscura consolidada.
- Azul marino como base.
- Verde esmeralda como acción y confianza.
- Violeta, azul y ámbar como estados secundarios.
- Se eliminó el lenguaje de casino y sorteos.
- Se mantuvo “Tareas” como eje principal.
